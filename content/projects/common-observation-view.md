<section class="case-section" aria-labelledby="integration-problem"><div><p class="eyebrow">01 / The problem</p><h2 id="integration-problem">The inputs<br>do not agree.</h2></div><div class="body"><p>The original hackathon asked how to represent heterogeneous observations when formats, units, timestamps and identifiers disagree. I built the prototype solo. The later console makes that integration inspectable: spatial picture first, selected track second, supporting evidence third.</p><p>The runtime shown here is later follow-on work, not a screen demonstrated during the original hackathon. Every track, sensor position, classification, uncertainty value and RF bearing belongs to a deterministic synthetic scenario. The grayscale Munich basemap is a visual reference, not a field installation.</p></div></section>

<section class="case-section" aria-labelledby="analyst-boundary"><div><p class="eyebrow">04 / Bounded local AI</p><h2 id="analyst-boundary">The model chooses<br>what to explain.</h2></div><div class="body"><p>A deterministic matcher identifies the synthetic scenario first. Qwen 3 4B chooses and orders catalog-approved explanation slots. The server validates the selected track, scenario, evidence keys and question ID. Templates supply every visible sentence; current fetched-frame values keep those facts up to date.</p><p>AI Watch shows two evidence points and a fixed evidence boundary. The separate Scenario Copilot reuses the packet for deeper inspection through approved question buttons. There is no free-text prompt and no action or recommendation path. Unavailable or invalid model output leaves a clearly labelled deterministic fallback.</p><p>Schema-valid model output demonstrates contract compliance. It does not establish verified judgment, calibrated uncertainty or field performance. RF remains bearing-only. The separate SENSE service serves retained evidence records; these captures do not demonstrate continuous camera-to-detector integration.</p><p><a href="./common-observation-reference.md#current-acceptance">Read acceptance and limits →</a> · <a href="../notes/small-evaluations.md">Engineering note →</a></p></div></section>
